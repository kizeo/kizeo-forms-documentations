# Site Docusaurus

Ce dossier contient le site [Docusaurus 3](https://docusaurus.io/) de la documentation Kizeo Forms.

La documentation complète du projet (installation, développement, build, traductions,
déploiement) se trouve dans le **[README à la racine du dépôt](../README.md)**.

Démarrage rapide :

```bash
npm install
npm start          # anglais
npm run start:fr   # français
```
